# 新图片待整理入口

## 用途
所有新上传、来源不明、主题暂不明确或尚未完成分类的图片先放在这里，避免散落在仓库根目录或被错误分类。

## 可收录格式
PNG、JPG/JPEG、WebP、GIF、SVG、ICO 等。保留真实扩展名，不要通过改扩展名伪装格式转换。

## 归档步骤
1. 上传时尽量保留原始文件名；名称重复时追加日期或版本号。
2. 识别主题、所属品牌/应用、用途，以及是否为动画或矢量图。
3. 移入最匹配的正式分类子目录。
4. 如果没有合适目录，创建新子目录并添加 README.md，说明用途、范围、命名规则和示例。
5. 更新 `../索引/图片清单.csv`，记录相对路径、格式、MIME、类型、大小、像素尺寸和备注。

建议文件名：`主题-用途-宽x高-v01.扩展名`。本目录是临时收件箱，完成分类后应移入正式目录。
