# 图片索引说明

本目录保存图片素材结构化清单，便于按名称、路径、主题、格式和文件大小检索。

## 文件
- `图片清单.csv`：当前仓库全部 134 张图片的逐文件登记表。

## 字段
- 文件名、相对路径、一级分类、二级分类：文件身份和归档位置。
- 格式、扩展名、MIME 类型、文件类型：真实图像格式信息。
- 文件大小(Byte)、文件大小(KiB)：文件体积，1 KiB = 1024 Byte。
- 像素尺寸：宽 × 高；未实际读取时填写“未实测”，不要从文件名推断。
- 备注：重复内容、待确认用途或其他归档说明。

每新增、删除、移动或替换图片，都应同步更新 CSV。移动时更新路径；替换内容时更新大小和尺寸。索引中的格式、MIME 和类型必须与实际文件一致。
