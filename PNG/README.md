# PNG 图片

本目录只存放 PNG 格式图片，MIME 类型为 `image/png`，属于无损位图，适合透明背景图标、界面资源和常规图片。

## 目录结构
`PNG/宽高比/分辨率/文件名.png`

宽高比目录为 `1x1`、`9x16`、`16x9`、`4x3`、`3x4`、`3x2`、`2x3`、`2x1`、`other`。每个比例下预建 100px、200px、256px、300px、500px、512px、720px、1080px、1440px、2K、4K、8K 分辨率目录。
