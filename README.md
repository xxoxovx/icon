# 图片素材库

本仓库用于统一保存、分类和检索图片素材。每个文件夹均配有 README.md，说明用途、收录范围和新增规则。

## 当前资源
- 图片：134 个
- 格式：PNG（.png）；MIME：`image/png`
- 类型：PNG 位图图像
- 总大小：3,300,511 Byte（3223.16 KiB）
- 像素尺寸尚未逐张读取；文件名中的 512px 仅是命名线索，不代表已实测分辨率。
- 逐文件信息见 [索引/图片清单.csv](索引/图片清单.csv)。

## 新增图片流程
1. 新图片先放入 `00_待整理_新图片入口/`，不要散放在仓库根目录。
2. 确认主题后移入对应子目录；若无合适目录，建立新目录并添加 README.md。
3. 保留原图，不覆盖旧版本；同主题不同版本递增版本号。
4. 更新 `索引/图片清单.csv`，记录文件名、路径、格式、扩展名、MIME、类型、大小、像素尺寸和备注。
5. 每个新目录必须有 README.md，写明用途、范围、命名规则和示例。

## 命名规范
建议 `主题-用途-宽x高-v01.扩展名`，例如 `ChatGPT-AppIcon-512x512-v01.png`。扩展名必须与真实格式一致；GIF 保留动画，SVG 保留矢量格式，不要仅修改扩展名伪装格式转换。

## 支持格式
当前文件均为 PNG；以后可收录 PNG、JPG/JPEG、WebP、GIF、SVG、ICO 等格式，并按真实内容填写 MIME 类型。PNG/JPEG/WebP 通常为位图，SVG 为矢量图，GIF 可能含动画。

## 备注
原始图片文件名和内容均保留。检测到 Git Blob 内容相同的文件不会自动删除，索引中会标注。当前像素尺寸未实测，避免把文件名中的 512px 误认为实际分辨率。
