# Image Library（图片素材库）

本仓库采用**英文文件夹和文件名、中文 README 说明**。图片按真实格式、宽高比和分辨率归档，方便长期扩展。

## 目录结构
```text
ImageLibrary/
├── PNG/  # PNG 位图图片，按宽高比和长边分辨率分类
│   ├── 1x1/  # 正方形 图片
│   ├── 9x16/  # 竖版9:16 图片
│   ├── 16x9/  # 横版16:9 图片
│   ├── 4x3/  # 4:3比例 图片
│   ├── 3x4/  # 3:4比例 图片
│   ├── 3x2/  # 3:2比例 图片
│   ├── 2x3/  # 2:3比例 图片
│   ├── 2x1/  # 约2:1宽幅 图片
│   ├── other/  # 其他比例 图片
├── JPG/  # JPEG 图片（.jpg）
├── JPEG/  # JPEG 图片（.jpeg）
├── WEBP/  # WebP 图片
├── GIF/  # GIF 动图或静态图
├── SVG/  # SVG 矢量图
├── ICO/  # ICO 多尺寸图标
├── BMP/  # BMP 位图
├── TIFF/  # TIFF 高质量位图
├── AVIF/  # AVIF 图片
├── HEIC/  # HEIC/HEIF 图片
├── INBOX/  # 新上传、格式或比例暂未确认的图片
└── INDEX/  # 图片属性索引
```

PNG 下已预建常见比例与分辨率目录：`100px`、`200px`、`256px`、`300px`、`500px`、`512px`、`720px`、`1080px`、`1440px`、`2K`、`4K`、`8K`。其他格式已建立格式根目录和常见比例目录，首次添加文件时在比例目录下建立对应分辨率目录。

## 宽高比规则
- `1x1`：正方形；`9x16`：竖版；`16x9`：横版。
- `4x3`、`3x4`、`3x2`、`2x3`：其他常见横竖比例。
- `2x1`：约 2:1 宽幅图；`other`：非标准比例。
- 文件夹使用字母 x 代替冒号，避免 Windows 等文件系统不支持冒号的问题。
- 允许约 1% 的比例误差；超出范围放入 `other`。

## 分辨率规则
- `100px`、`200px`、`256px`、`300px`、`500px`、`512px`、`720px`、`1080px`、`1440px` 表示长边实际像素值。
- 非标准尺寸按实际长边命名，例如 `600px` 或 `1536px`。
- `2K`：长边 1920–3839 px；`4K`：3840–7679 px；`8K`：7680–15359 px。
- 分辨率按原始图片像素计算，不按文件名猜测，也不在归档时自动缩放。

## 新图片归档流程
1. 识别真实格式，放入 PNG、JPG、WEBP、GIF、SVG 等对应格式目录。
2. 读取实际宽度和高度，计算比例，选择宽高比目录。
3. 按长边像素选择分辨率目录；目录不存在时按规则新建。
4. 每个新建文件夹都必须添加 README.md，用中文说明用途、比例、分辨率和归档规则。
5. 文件名统一使用英文，建议 `Subject-Variant-v01.ext`，避免中文文件名。
6. 更新 `INDEX/image-index.csv`，登记路径、格式、尺寸、MIME、文件大小和备注。

## 特殊格式
- SVG 是矢量图，没有固定像素分辨率，放入 `SVG/VECTOR/`。
- ICO 可能包含多个尺寸，放入 `ICO/MULTI_SIZE/`。
- GIF 保留动画，不要转换成静态 PNG。
- JPG 与 JPEG 是同一种 JPEG 格式，分别提供目录以兼容两种扩展名。
